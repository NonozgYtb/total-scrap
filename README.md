# Total Scrap

Un petit projet pour facilement voir les stations Total autour de soi (plusieurs recherches possibles) qui ont encore certains carburants disponibles dans un rayon donné.
Projet créé à la main pour la partie scraping du site Total, avec l'IA pour l'interface.

## Mise en place

Copier le fichier `src/config.example.ts` en `src/config.ts` et remplir les informations nécessaires (nom & slug de la recherche, coordonnées GPS, rayon de recherche, carburants à rechercher).
Copier le fichier `docker-compose.example.yml` en `docker-compose.yml` et modifier au besoin les informations (port, réseau...).
